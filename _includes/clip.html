HDR sources come first, offered only to (dynamic-range: high) displays, then SDR; within each, a source twice the smallest width is offered to displays of 2 dppx and more. The video's width and height are half the largest source's pixel size (the smallest size when there are two), so a 1920x1440 source on a 2x display and a 960x720 source on a 1x display are both 1:1 without JavaScript; assets/js/render.js sizes the video for other pixel ratios and keeps a poster only at its own pixel size. A single file of known size can be given as src, width, height (and type).
